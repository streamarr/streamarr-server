Binary release: https://github.com/jellyfin/jellyfin-ffmpeg/releases/tag/v8.1.2-4

Targets: portable Linux GPL, amd64 and arm64

Corresponding Source
====================
The source code for FFmpeg, the bundled libraries, and the scripts controlling
compilation is available without charge at the upstream repositories and exact
revisions listed below. Obtain FFmpeg and its Jellyfin patches/build recipes at:
https://github.com/jellyfin/jellyfin-ffmpeg/tree/6c051dec38eb0e88d2d4d3c54b13014bf69f9799
Source archive:
https://codeload.github.com/jellyfin/jellyfin-ffmpeg/tar.gz/6c051dec38eb0e88d2d4d3c54b13014bf69f9799

Follow the upstream builder/README.md. From builder/, run ./makeimage.sh linux64 gpl
and ./build.sh linux64 gpl; use linuxarm64 instead of linux64 for ARM. The
builder/scripts.d recipes select library revisions, build
options, generated code, and any changes in builder/patches. These changes are
part of the Corresponding Source; an unpatched library release alone is not the
complete source for a patched component. Streamarr redistributes the upstream
binaries unchanged. Its packaging scripts are in buildpacks/ffmpeg in:
https://github.com/streamarr/streamarr-server

For a Git source entry below, clone its repository and check out the listed
revision (git checkout --detach REVISION); initialize submodules when the pinned
recipe requires them. For LAME, use svn checkout -r 6531 with the listed URL.
The source entries also identify relevant generated-loader and build-support
inputs; not all such entries are standalone libraries linked into the binary.

The stripped FDK AAC source, including upstream modifications, is available at:
https://gitlab.freedesktop.org/wtaymans/fdk-aac-stripped/-/tree/529b87452cd33d45e1d0a5066d20b64f10b38845
Its license and upstream modification notice are included in
notices/fdk-aac-stripped/NOTICE.txt and notices/fdk-aac-stripped/README.fedora.txt.
Streamarr selects FFmpeg's native aac encoder, not libfdk_aac. This does not remove
the stripped FDK code from the redistributed executables.

License and inventory information
=================================
LICENSE.txt contains GPLv3. notices/ffmpeg/ includes FFmpeg's license overview,
GPL/LGPL texts and per-file copyright information from the locked fork revision.
Other notices/ subdirectories retain bundled-component licenses and attribution.
These components retain their own copyright notices and license terms.

notices/manifest binds this inventory to the source revision and both archive
checksums. notices/sources.json records component roles, architecture scope,
source revisions, build recipes, notice origins and notice SHA-256 checksums.
Checksums there describe the installed notice files, not the binary archives.
Header-license excerpts are marked; text may have a normalized final newline.
The two buildconf files record the binaries' configure flags used as the starting
point for the inventory; transitive static code and generated loaders were then
traced through the locked recipes and submodule/dependency pins.

System glibc shared libraries and optional GPU driver implementations are not in
the portable tarballs. Their notices belong to the image/base-system packages that
provide them. glibc startup/nonshared support is inventoried separately. GCC runtime
code is linked statically and its Runtime Library Exception is
included here. The upstream builder does not pin Implib.so: its inventory revision
identifies the notice source, not a proven revision of the binary's generator.
