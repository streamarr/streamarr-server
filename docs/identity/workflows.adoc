= Identity and Authorization Workflow Checklist

One row per user-visible workflow that ADR 0024 / ADR 0025 / ADR 0026 govern. A row is complete
when its server PR is merged and each client column reads *complete* (with the PR), *deferred*
(no client work in this stack), or *n/a*. The definition of done for the identity rebuild is every
row complete; a PR that ships a workflow adds or completes its row in the same change.
