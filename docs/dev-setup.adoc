= Developer Setup

== Prerequisites

* **JDK 25** (LTS) -- https://www.azul.com/downloads/?version=java-25-lts[Zulu] or https://adoptium.net/[Temurin]
* **Docker** -- for PostgreSQL and the standalone worker (development and integration tests)
* **Python 3** (`python3`) -- standard-library-only CI artifact regression tests
* **Git** with GPG signing configured

== Clone and Build

[source,bash]
----
git clone git@github.com:streamarr/streamarr-server.git
cd streamarr-server
cp .env.example .env
# Edit .env and set TMDB_API_TOKEN
./mvnw clean compile
----

== Running PostgreSQL

[source,bash]
----
docker compose --env-file worker-image.env --env-file .env up -d postgres
----

Compose loads the checked-in worker image pin before local settings from `.env`.
This starts PostgreSQL 18 on port 5432 with credentials from `.env`.

== Running the Server

[source,bash]
----
./mvnw spring-boot:run
----

The server starts on `http://localhost:8080` with the `dev` profile active.

Playback and media probing also require a connected transcode worker.
The worker listener defaults to loopback in every profile.
See link:distributed-transcoding.adoc[Distributed Transcoding] for worker setup and source namespace mappings.
When running the server on the host, set `STREAMING_REMOTE_SOURCE_ROOT` to its media directory and map the same content on the worker.

The `dev` profile enables GraphiQL at `http://localhost:8080/graphiql` and auto-populates the database with sample data via `DevDataInitializer`.

=== Cookie-Mode Login in Safari

Auth cookies are `Secure`, and Safari -- unlike Chrome and Firefox -- refuses to store or send a `Secure` cookie over plain HTTP even on `localhost`.
Cookie-mode login therefore appears to succeed while every following request answers `AUTHENTICATION_REQUIRED`.

Set `AUTH_COOKIES_ALLOW_INSECURE=true` to drop the attribute:

[source,bash]
----
AUTH_COOKIES_ALLOW_INSECURE=true ./mvnw spring-boot:run
----

The flag is honored only while a `dev`, `development`, or `test` profile is active; setting it anywhere else fails startup.
It drops `Secure` from both credential and CSRF cookies. Credential cookies stay `httpOnly` and `SameSite=Strict`, so application code still cannot read the tokens.
Because the `__Host-` prefix requires `Secure`, the script-readable CSRF cookie switches from `__Host-XSRF-TOKEN` to the development-only `XSRF-TOKEN`; the web client recognizes both names.

== Running Tests

[source,bash]
----
# Unit tests only
./mvnw test

# Unit + integration tests (PostgreSQL and the standalone worker use Testcontainers)
./mvnw verify
----

Integration tests start PostgreSQL and the standalone worker with Testcontainers.
Worker integration tests, HLS smoke tests and CI use the immutable image in `worker-image.env`.
Renovate proposes digest and version updates. Server CI verifies compatibility before human merge.
Set `STREAMARR_WORKER_IMAGE` or pass `-Dstreamarr.worker.image=<image>` to test a local worker build.
No host FFmpeg installation is needed.

== Container Images

When the Maven version is `X.Y.Z-SNAPSHOT`, successful `main` CI publishes that exact tag for both architectures.
Stable `X.Y.Z` tags are published by the release workflow.
The worker follows the same convention. The server consumes its tag and digest from `worker-image.env`.
Renovate refreshes snapshot digests and proposes the stable version when it is released. Later snapshots require an explicit opt-in.

== Worker Protocol

The server publishes `src/main/protobuf` to `buf.build/streamarr-org/transcode` after merges to `main` through `.github/workflows/buf-publish.yml`.
Use `buf-consumer-pin.properties` from a successful run's `worker-contract-pin-<git-sha>` artifact when updating the worker's exact SDK dependency version.
To verify from a matching published checkout, run `bash .github/scripts/verify-buf-consumer.sh` with Java 25, Buf and jq available.

== jOOQ Code Regeneration

After modifying Flyway migrations, regenerate jOOQ types:

[source,bash]
----
docker compose --env-file worker-image.env --env-file .env up -d postgres
./mvnw generate-sources -P generate-jooq-code
----

== Code Formatting

Google Java Format is enforced via Spotless:

[source,bash]
----
# Check formatting
./mvnw spotless:check

# Auto-format
./mvnw spotless:apply
----

== TMDB API Token

Get a free API read access token at https://www.themoviedb.org/settings/api and add it to your `.env` file.

== Observability (Optional)

To enable OpenTelemetry export to Grafana Cloud:

[source,bash]
----
# Add to .env:
COMPOSE_PROFILES=observability
GRAFANA_CLOUD_INSTANCE_ID=<your-id>
GRAFANA_CLOUD_API_KEY=<your-key>
GRAFANA_CLOUD_OTLP_ENDPOINT=<your-endpoint>

# Start with observability:
docker compose --env-file worker-image.env --env-file .env --profile observability up -d

# Run server with observability profile:
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev,observability
----
